# Owner Portfolio Overview

## Scope
Owner Portfolio muestra el catalogo de SaaS activos por vertical y los indicadores agregados para Campamento Base.

## Visibilidad
- El owner de Campamento Base ve lo que cada SaaS paga a Drako y los costes vendor imputados por vertical.
- No se expone la facturacion completa ni el margen interno del negocio final (peluqueria, clinica, etc.).
