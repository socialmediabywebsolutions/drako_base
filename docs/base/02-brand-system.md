# Sistema de Marca y UI (Drako)

## Identidad
- Tecnología seria + futuro cercano.
- Voz: directa, clara, útil. Un toque épico solo si aporta (sin humo).

## UI Base (obligatorio)
- Tema: **oscuro**
- Paleta: grises + **acento celeste** (acciones/foco).
- Layout estándar en TODAS las secciones:
  1) Izquierda: navegación + historial
  2) Centro: contenido principal
  3) Derecha: chat/IA + panel de acción

## Orientación visual por sección
Cada sección puede tener un “color de referencia” sutil (badge/borde), pero:
- El acento global sigue siendo **celeste**
- No mezclar estilos de iconos

## Microcopy (regla)
Nada de “Internal Server Error” sin explicación.
Siempre: **qué pasó + qué hacer**.

Ejemplo 503:
- reason: binding-missing
- hint: “Añade binding DRACO_DB en Cloudflare Pages → Settings → Functions → D1 bindings.”
