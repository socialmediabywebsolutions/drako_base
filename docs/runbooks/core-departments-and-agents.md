# Core departments and agents

This runbook documents the core departments and baseline agents that are seeded for every SaaS.

## Customer Experiences
- Department slug: customer-experiences
- Purpose: Owns customer tickets, satisfaction signals, and knowledge updates.
- Agents:
  - cx-triage: Classifies incoming CX tickets and routes them to the right owner.
  - cx-knowledge-agent: Keeps help content updated and highlights documentation gaps.
  - cx-satisfaction-monitor: Tracks CSAT signals and flags service risks early.

## Technical Operations
- Department slug: technical-operations
- Purpose: Handles runtime incidents, routing stability, D1 health, and deploy support.
- Agents:
  - tech-incident-triage: Triages runtime incidents and prioritizes urgent fixes.
  - tech-runtime-operator: Monitors runtime, D1 health, and routing reliability.
  - tech-security-ops: Coordinates security response and production hardening.

## Campamento Base Engineers
- Department slug: campamento-base-engineers
- Purpose: Internal engineering agents for the factory and platform work.
- Agents:
  - factory-architect: Designs SaaS factory systems and core platform patterns.
  - factory-implementation-planner: Plans internal builds and sequencing.
  - factory-code-reviewer: Reviews factory changes and flags regressions early.
